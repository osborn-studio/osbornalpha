# Macro Workbench (guest view) + allocation template card

`src/app/(app)/macro/page.tsx` → `src/components/macro/MacroWorkbench.tsx`. When `MACRO_JUDGMENTS_ENABLED` is not `1` (`src/lib/macro/flags.ts`), the workbench renders the static `AllocationTemplateCard` (`src/components/macro/AllocationTemplateCard.tsx`, values in `src/lib/macro/allocation-template.ts`, copy in `messages/{zh,en}/macro.json` → `judgment.allocation`) in place of the judgment slot (#231). All other workbench data loads client-side from `/api/macro/*`, which requires a signed-in session (`requireSessionUser`).

## Sub-features
- Heading `宏观工作台` / `Macro workbench`, region toggle (`?region=US|CN`) and the tab row (`nav` named `工作台分区` / `Workbench sections`) `概览 / 指标 / 关联 / 方法与来源` (`Overview / Indicators / Correlation / Method & sources`), linking `/macro?region=<R>&tab=<overview|indicators|correlation|methodology>`. With `MACRO_STRATEGY_ENABLED` not `1` (`src/lib/macro/strategy/flags.ts`, read by `src/app/(app)/macro/layout.tsx` since #300) the row has no `传导 / 历史 / 复盘` links, and `/macro/transmission`, `/macro/history`, `/macro/review` render the app 404 page (`notFound()`). With the flag on the row has seven links.
- Without a session/DB the overview fails closed with `读取失败：unauthenticated` (`states.loadFailed`). No invented macro data.
- Allocation template card (since #262 a research-ui `MarkCard kind="hypothesis"`: `<section data-mark="hypothesis">` with the `假设` / `Hypothesis` tag and an `h2` title `资产配置假设模板` / `Asset allocation hypothesis template`; it no longer carries an `aria-label`, so it is not a named region): pills `假设框架 · 未经检验 · 不构成投资建议`, the `静态参考` / `Static reference` marker (shown only when no regime is selected), four regimes in clock order `复苏 过热 滞胀 衰退` / `Recovery Overheat Stagflation Recession`, each with 股票/债券/商品/现金 weights summing to 100% and a tilt note, the Merrill Lynch Investment Clock source note, and the version `macro_allocation_template@v1`. The card is region-independent.
- Shared research footer (#262, `MacroResearchFooter` → `research-ui/ResearchFooter`, `footer[data-research-footer]` inside `#macro-sources`) on every tab except 关联: disclaimer `本页内容不构成投资建议。…` / `Nothing on this page is investment advice. …`, source chips from the series registry, and a `方法与来源` / `Methods and sources` link to `/macro?region=<US|CN>&tab=methodology` (falls back to a plain methodology-tab link when there are no source chips).
- Shared research chain (#254, `nav` named `研究链` / `Research chain`, `src/components/research-ui/{chain.ts,ResearchChain.tsx}`, mounted by `src/app/(app)/layout.tsx` under the top bar): `01 宏观策略 → 02 行业研究 → 03 公司研究 → 04 外资研报 → 05 专题研究`. On `/macro`, 01 is `aria-current=page`; 02 links to `/intel/industries?scheme=sic` (#266 dropped the `metric` param; the industry page picks its own default), 03 to `/intel/companies`; 04 and 05 are `未服务` / `Not served` spans without a link (04 opens only when the foreign-research public flag is on, which needs service-role Supabase — #252/#260; 05 links to `/intel/topics` only when the topics public flag is on — `TOPICS_ENABLED=1` plus `topic_settings.public_enabled` over service-role Supabase, #278 `src/lib/topics/public-flag.ts` — see [research-hub-topics.md](research-hub-topics.md)).
- With judgments enabled and a published F4 card, the same card is shown inside the judgment slot with the selected regime marked `aria-current` / `当前`. Not driveable locally (see Gotchas).

## How to get to it (user POV)
Click `宏观` in the top nav (desktop) or the bottom tab bar (phone), or the `01 宏观策略` step of the research chain (or open `/macro`, `/today`, `/dashboard`). The card sits under the overview notice. Switch `中国 CN` to see that it does not change.

## Driving it with CDP browser
`node $S/drive.mjs macro` (guest mode only; in gate mode `/macro` redirects to login). Three fresh contexts: zh-CN `/macro`, zh-CN `/macro?region=CN`, en-US `/macro`. Each checks the 200 + heading; exactly one `section` holding the card's `h2` title, with the static-reference marker; that this section is `data-mark="hypothesis"` with the `假设` / `Hypothesis` tag; the four regime names in order; that each regime's four `dd` percentages sum to 100; that no row has `aria-current`; the version + source note; the research footer (disclaimer + exactly one methods link for the page's region, `US` or `CN`); and the research chain (exactly one `研究链` / `Research chain` nav, steps 01–03 linked with 01 current, 04/05 `未服务` / `Not served` with no `/intel/foreign-research` or `/intel/topics` link). Each pass also checks the tab row: exactly the four view tabs with region-scoped hrefs and no `/macro/{transmission,history,review}` link (#300). A fourth zh-CN context opens `/macro/transmission`, `/macro/history` and `/macro/review` and checks each renders the app 404 page (`页面不存在`) with no tab row. The zh `/macro` pass also checks the fail-closed `读取失败` notice. Screenshots `macro-zh.png`, `macro-cn.png`, `macro-en.png`.

## Gotchas
- The data-mark / `Hypothesis` tag check, the English title `Asset allocation hypothesis template`, and the research-footer check only hold from #262 on. On a checkout before #262 those 11 checks fail (en card not found by its old title `Asset allocation assumption templates`, no `data-mark`, no footer); that is expected, not a regression.
- `launch.sh` also pins `MACRO_STRATEGY_ENABLED=` (empty) so the four-tab / 404 checks hold whatever a dotenv says. The three strategy routes answer HTTP 200 under `next dev` even though they render the 404 page: `src/app/(app)/loading.tsx` starts streaming before `notFound()` runs. Assert the rendered page, not the status (same as the topics-off pages). Before #300 the row always listed seven links, so the tab-row check fails on older checkouts.
- `launch.sh` pins `MACRO_JUDGMENTS_ENABLED=` (empty) so a checkout's dotenv cannot switch the judgment slot on. With it set to `1` and no DB the slot shows its unavailable state instead of this card; that is not what this journey asserts.
- Not provable locally (need a migrated macro DB + signed-in session, or ops credentials): the investment clock, weighted breakdown and clock metadata (#231/#232: the clock takes the highest well-formed `macro_regime` method version and needs exactly one card of it), the Fed liquidity series `WALCL` / `WTREGEN` / `RRPONTSYD` from the unhashed display registry (#227/#233, `src/lib/macro/display-catalog.ts`), CN policy-rate quote events and LPR/AFRE official-HTTP collection (#228, `src/lib/macro/parsers/{chinamoney,pboc-afre}.ts`), `/api/macro/series/[id]` (+ `/versions`), and `POST /api/cron/macro-sync` (cron secret).
- The clock preview (`scripts/preview/macro-clock.ts`, `src/components/macro/ClockPreview.tsx`) is a local esbuild developer preview on captured fixtures, never mounted by Next. It is not a user surface and is not driven here.
