- Required `superpowers:executing-plans` / `superpowers:subagent-driven-development` skills are unavailable in the installed skill catalog and skill directories. Used the available TDD workflow directly; no subagents or state-changing git commands were used.
- Shared locales, NAV, audit log and client-boundary registry changes are provided here per commander instructions, rather than edited. Local message parity checks validate these exact JSON fragments.

- Date parsing checks validity before `toISOString` (invalid months otherwise throw a RangeError/500); rejects non-calendar dates and year zero with 400. Closing a scale checks `valid_to > valid_from` before the DB to satisfy its constraint.
- URL parsing validates a real HTTP(S) hostname, beyond the plan's regex; rejects null array inputs instead of silently turning them into empty arrays.
- Local audited-write error mapping converts DB `duplicate_key`, `scale_closed`, and `analyst_immutable` to 409; the shared C1 mapper does not contain those codes.
- Analyst updates verify membership in the URL institution, preventing cross-institution reassignment. An explicit unknown analyst ID returns 404 (`analyst_not_found`); creation uses an omitted ID.
- Tests add guards for detail/close routes, duplicate/closed scales, ownership, audit failure tolerance, failed DB writes, page gating/rendering, local fragment parity and client graph coverage. No existing assertions were removed or weakened.
