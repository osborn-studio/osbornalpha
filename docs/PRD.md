# PRD — Stock Monitor

> 个人股票池每日 AI 监控产品需求

## 1. 一句话定义

> 每天早上把我的股票池交给 AI，模拟多位投资大师视角辩论，给我一份 5 分钟可读完的决策辅助简报。

## 2. 目标用户

**个人投资者**（项目作者自用），关注三个市场：A 股 / 港股 / 美股。

## 3. 核心场景

- 早上 8:30 通勤路上：Telegram 收到一份当日 brief
- 早上 8:30 工位：邮箱收到 HTML 美化版
- 周末复盘：Web 端查历史 + 回看打脸记录

## 6. 非功能需求

| 类别 | 要求 |
|-----|------|
| 性能 | 单次简报生成 ≤ 5 分钟 |
| 可靠性 | 调度命中率 > 99% |
| 成本 | 单日 ≤ $5（LLM）+ ¥40（数据）|
| 安全 | API key 全部 env 变量；推送加密 |
| 合规 | 全部外发必带 disclaimer；不存储仓位 |
| 隐私 | v0 全本地运行（Mac mini）|
| 国际化 | v0 中文；v2 加英文 |

## 7. 范围外（NOT in scope）

- ❌ 实时分钟级行情
- ❌ 自动下单 / 仓位管理
- ❌ 期权策略 / 加密货币
- ❌ 社交评论 / 直播
- ❌ 移动 App（用 Telegram + PWA 替代）
- ❌ 自建技术指标库（用 Alpha Vantage / TradingView 现成的）
- ❌ AI 聊天问答（这不是另一个 ChatGPT）

## 8. 风险与缓解

| 风险 | 缓解 |
|-----|------|
| LLM Hallucination 给错误判断 | 强制 cite + confidence + 多视角对冲 + 30天打脸记录 |
| 数据源断供 | 双源冗余设计 |
| LLM 成本失控 | 每日 budget cap，超过自动降级 Haiku |
| 用户期望"涨跌预测" | 文案严格规范，反复强调"决策辅助" |

## 9. 成功指标

- **DARR**：Daily Active Reader Rate（自己每天打开率）
- **30 天信号命中率**
- **30 天调度成功率**
- **单日总成本**
