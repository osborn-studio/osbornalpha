- Demonstrate one independently transcribed, source-pinned gold case through exact decimal comparison, provenance validation, and a deliberately incorrect actual value.
- Prove that empty coverage, truncated reads, wrong units, stale explanations, and incomplete evidence cannot produce release approval.
- Run real-role database tests, including reference write denial, persistence failure recovery, decimal serialization, and origin deletion behavior.
- Verify deployment identity and CDN behavior experimentally; confirm Vercel settings and CI artifact retention.
- Locate retained ChaosAI capture bytes and approve the private-evidence publication policy.
