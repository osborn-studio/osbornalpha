## Verdict

**not ready**

The specification still permits non-primary and unreplayable data, conflicts with landed DQ and quota contracts, and exposes judgments outside the required F4 gate. Its core source mappings and historical availability claims need correction before an implementation plan can reliably scope the work. The prescribed fixes stay within P1/P2; no missing P3/P4 functionality is reported.
