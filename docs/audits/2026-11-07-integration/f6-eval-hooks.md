# F6 eval hook disposition

`extraction_gold` remains disabled pending the D8 gold licence decision. `adaptF3Document` is an explicit eval/test entry point over the production `DocumentsDb` read contract. It accepts public PDF documents only, reads the current extraction and its complete one-based page set, and maps non-rejected field/financial-fact candidate values without changing their strings. F3 citation boxes use bottom-left PDF points; the adapter converts them to F6 top-left PDF points using the cited page height. A missing document, extraction, page, or valid value citation is a whole-document read error; superseded and private/licensed rows are excluded. F3 has no withdrawn document status, so withdrawal requires an upstream representation before it can be mapped separately.

`judgment_calibration` remains disabled. F4's registered `macro_regime@v1` is categorical. The private `recommendation_call@v1` card carries a probability but is self-assessed from owner-writable scoring data and has no auditable settled-forecast export or F4 thresholds. The F4 adapter returns `no_probability_methodology` and rejects a future probability registry entry until a calibrated, visible settlement read boundary is implemented. No categorical score is converted to `p`.
