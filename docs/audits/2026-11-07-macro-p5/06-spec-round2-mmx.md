## Round-1 disposition

- **M1: closed** — F4 card and same-snapshot input are now mandatory before any regime numbers are exposed; F4 failure paths return no numeric data.
- **M2: closed** — Rule evaluation and observation selection are server-side; the client is limited to presentation.
- **M3: still open** — The snapshot still does not freeze the weight manifest. `catalog_version === CATALOG_VERSION` is only a proxy and does not prove that an old snapshot used today’s `WEIGHTS_V1`; `weight` still comes from `regionWeights(region)`.
- **M4: closed** — `coverage_below_threshold`, `zero_score`, and `record_missing` are separated.
- **M5: closed** — `by_state.weight` is defined as mutually exclusive grouping of the frozen scoring rows, with a denominator invariant.
- **M6: closed** — A rules-version mismatch is now a snapshot-level `version_unsupported` state.
- **M7: closed** — F4 card shape, method identity, lifecycle, and stable driver ordering are specified.
- **M8: closed** — Reconciliation now permits accumulated r6 rounding and defines a tolerance.
- **M9: closed** — The client no longer selects observations; the server projects manifest references.
- **M10: closed** — `record_missing` is distinguished from a stored null regime.
- **M11: still open** — v1 retirement remains conditional on an unverified retire path, and the v2 factory is still not guaranteed to exclude v1’s catalog-bound import closure.
- **M12: closed** — Method identity is now consistently `id='macro_regime'`, `version='v2'`, key `macro_regime@v2`.
- **M13: closed** — Catalog activation is deferred to D5 with a corresponding v3 method version.
- **M14: closed** — MLF now uses month-end event observations, with no carry-forward or interpolation.
- **M15: closed** — `html_text` was removed; MLF requires a table locator.
- **M16: closed** — Publisher/via are distinguished, with a source-verification task.
- **M17: closed** — LPR quote dates are preserved and monthly scoring rows use the last quote in the month.
- **M18: closed** — WTREGEN’s monthly value is now explicitly the last weekly observation, not a month-end week average.
- **M19: closed** — The catalog-manifest change is explicitly assigned to D0/v2.
- **M20: closed** — Presets are explicitly read-only, whitelist-based, and excluded from user quota and persistence.
- **M21: closed** — The active-snapshot resolver, cutoff, code version, and memo key are specified.
- **M22: partially closed** — Some CHECK changes are listed, but exact current constraint names and old/new legal sets remain partly unverified.
- **M23: closed** — Parser row keys, duplicate handling, empty values, and required header matching are defined.
- **M24: closed** — Display precision, units, rounding, and negative-zero handling are specified.
- **M25: closed** — Probability/confidence/reliability/forecast wording is prohibited outside the explicit non-probability disclaimer.
- **M26: closed** — Explicit FX/GDP type-boundary tests are required.
- **M27: closed** — `not_in_catalog` is limited to real `RESPONSE_DIMS_V1` entries.
- **M28: closed** — Published design canvases are identified.
- **M29: closed** — Missing/restricted rows have explicit null latest values and row states.
- **M30: closed** — Invalid values are excluded by server-side eligibility; the client does not perform `Number` classification.
- **M31: still open** — Row status, reason, and unit still come from the current catalog rather than a frozen per-snapshot catalog manifest.
- **M32: closed** — The new clock response contract is explicitly versioned.
- **M33: closed** — Marker deduplication, ordering, and the six-event limit are defined.
- **M34: closed** — Missing asset changes are not drawn as zero.
- **M35: closed** — The benchmark environment, cold/hot runs, sample count, and median are specified.
- **M36: closed** — Per-series first-period bounds are specified.
- **M37: closed** — The balance-derivation fallback was removed; only an official YoY column is allowed.
- **M38: closed** — Pink Sheet remains a separate plan and is not implemented in P5.
- **M39: closed** — The snapshot observation union and F4 gather-count behavior are explicitly addressed.
- **M40: closed** — Deliberate corruption magnitudes and boundary fixtures are specified.
