# 可转债策略核心引擎 — 严谨规格说明 (CB Strategy Spec)

> Companion annex to `../hedge-fund-ai-prd.md`. Produced by specialist subagent (CB strategist), 2026-06-03.
> 范围: 中国境内交易所**公募可转债**（沪深）。不含 EB（可交换债）、私募可转债（须单列规则）。
> 性质: 决策辅助规格，非投资建议。每个阈值为**起点默认值**，标 **[PM]** 处须基金经理/风控拍板。
> ★ 关键校正（相对 PRD v1 §3.2）: PRD 把"债底安全/正 YTM = 下有保底"列为下行保护——**这是 2021 年后的过时假设**。本规格把信用/退市/违约风险升为**一等约束（硬排除）**，而非软加权项（§3）。

---

## 0. 符号约定
一张面值 **100 元**；交易所转债报价为**净价**，YTM/纯债估值须用**全价**（净价+应计利息）。
`P_cb` 净价 · `S` 正股价 · `K` 当前转股价(动态) · `CR=100/K` 转股比例 · `CV` 转股价值 · `Prem` 转股溢价率 · `BF` 纯债价值 · `BP` 纯债溢价率 · `YTM` 到期收益率 · `ADV` 日均成交额 · `OS` 剩余规模。

## 1. CB 因子模型

### 1.1 转股价值 CV
`CV = (100/K)*S = CR*S`。K 用最新转股价（下修/送转除权调 K）。CV 是股性锚；P_cb 长期不显著低于 CV（T+0 转股次日卖正股，存隔夜风险，微偏离可持续）。

### 1.2 转股溢价率 Prem
`Prem = (P_cb/CV − 1)*100%`。高→股性弱/贵/向上弹性透支；低/负→股性强/贴正股（深度价内 delta≈1）。**陷阱[PM]**: 高价+低溢价(强股性临强赎) ≠ 低价+高溢价(强债性防御)；双低必须同看两维。

### 1.3 双低 Double-Low — 组合打分（核心）
经典（集思录口径，混合量纲约定俗成）: `DoubleLow = P_cb + Prem`（Prem 取百分数数值）。**升序，越小越双低。**
推荐生产版（可调）: `Score_DL = P_cb + k*Prem`，默认 `k=1.0` **[PM 可调 0.7–1.5]**。
推荐截面排名标准化（跨期稳定）: `Score = w_p*rank_pct(P_cb) + w_prem*rank_pct(Prem)`，默认 0.5/0.5，升序取前 N。
`k` 是风格旋钮 **[PM]**：risk-on 调高 k（吃弹性），risk-off 调低 k（重债性）。辅助因子（加权/过滤，非主导）: ytm_floor（仅在过 §3 信用门后有意义）、liquidity（ADV 分位）、size（OS）、剩余期限。

### 1.4 纯债价值 BF — 含告诫
`BF = Σ C_t/(1+r)^t + Redeem_n/(1+r)^n`。C_t 逐年递增票息（逐券读募集说明书）；Redeem_n 到期赎回价（含税口径逐券，典型 106–115，**不可硬编 110**）；r = 同评级同久期企业债 YTM（中债估值曲线按评级取）。BP=(P_cb−BF)/BF。
> ★ **告诫（PRD v1 缺失）**: BF 是 **"无违约假设下"** 的理论下限；r 因信用恶化跳升则 BF 坍塌；违约/退市时债底**不成立**（回收率可能远低于面值）。**BF 是条件下限，非保证地板。** 排序必须先过 §3 信用硬门。

### 1.5 YTM — 含失效条件
求 YTM 使 `P_cb_dirty = Σ C_t/(1+YTM)^t + Redeem_n/(1+YTM)^n`（全价）。正 YTM = 持有到期且不违约有正回报。税务[PM]: 票息/赎回利息所得税影响税后 YTM。
> ★ **两条失效（须硬编为状态机）**: ① 一旦**有条件强赎触发并公告**，债券提前终止，YTM 现金流作废→持有人在"转股 vs 接受强赎价(≈面值+息,100–103)"间选择；强赎价远低于临强赎市价，不转股巨亏。**强赎公告后 YTM 置 N/A，切强赎处置(§2.1)。** ② YTM 假设零违约；违约/退市下是纸面数字(§3)。

### 1.6 规模/流动性
`ADV=mean(成交额,20日)`；换手=当日成交额/(OS*100)（T+0 致换手常高于正股）；OS=未转股面值。**流动性硬过滤: ADV≥2000万[PM]**。**OS 双边[PM]**: <1亿剔除/限重（易强赎/操纵/冲击大）；过大(>50亿,银行转债)限重非剔除（弹性钝）。

## 2. 条款机制 — 逐券按募集说明书解析
> **总则: 条款逐券不同（阈值/天数/口径），引擎须逐券解析存入 clause_rules，不可全局硬编。** 下列为最常见值+变体。

### 2.1 有条件强赎（最重要）
最常见: `正股收盘价 S ≥ K*130%，任意连续30交易日中达15日 → 发行人可按(面值+当期息)强赎(赎回价≈100–103)`。
变体: 计数 15/30 最常见，亦有 20/30、10/20；阈值 120%/125%/130% 不一；还有**剩余规模触发**强赎(未转股余额<3000万无条件赎)；发行人有权**不行使**(博弈点[PM])。
影响: 临强赎市价常被股性顶到 130–200，若被赎未及时转股/卖出=灾难亏损。**引擎**: 进度计数 `redemption_progress=days_met/days_required`；≥7/15 黄色预警；公告满足/决定行使→红色**强制减/清**；已公告进摘牌倒计时→`exclude:near_forced_redemption`；触发后 **YTM置N/A**。注: 多数转债以"强赎离场"为正常退出(正股涨→强赎→转股获利)；坏的是"不知情被按面值赎"——引擎价值=确保强赎前主动了结/转股。

### 2.2 有条件回售
最常见: `S < K*70%，任意连续30交易日 → 持有人可按(面值+息,≈100–103)回售`。变体: 阈值 70%(亦 80%)；**多数券仅存续期最后2年有回售**(前期无保护)——临近回售期低价券下有支撑，远离的没有[PM]。影响: 回售价≈面值=接近债底硬支撑(仍以不违约为前提)；发行人为避回售有强烈**下修**动机(§2.3)→回售压力是下修前导，正向 catalyst[PM]。

### 2.3 向下修正转股价（下修）
触发(董事会提议+股东大会通过): 常见 `S < K*85%~90% 累计若干日 → 可提议下修 K`；新 K 不低于股东大会前20日均价与前1日均价之较高者(且≥每股净资产)。机制: K↓→CR↑→CV↑、Prem↓→股性增强、价格通常上行。**博弈[PM]**: "下修预期"是核心 alpha(临回售期+财务紧张+股价低迷=高下修概率)，但须股东大会通过(大股东可能反对)、对正股利空(稀释)。下修博弈是**事件驱动子策略，非双低主线**，单列 sleeve 并标事件不确定性。

### 2.4 到期赎回
`到期未转股: 按(面值+末期息)赎回，含税价典型≈106–115(逐券读,不可硬编)`。是 YTM 终点现金流(§1.5)。**临到期处置[PM]**: <6月时间价值耗尽，深度价外向赎回价收敛弹性消失；默认 `exclude:near_maturity`——PRD 30天过严，建议 <6月观察/降权、**<30天硬排除**。

### 2.5 速查
| 条款 | 触发 | 对价格 | 动作 |
|---|---|---|---|
| 强赎 | 正股强(≥130%K,15/30) | 短期顶高但赎回价≈面值 | 临近→减/清；防被按面值赎 |
| 回售 | 正股弱(<70%K,30d,仅回售期) | 接近面值硬支撑(无违约前提) | 临回售期低价券→优选防御 |
| 下修 | 正股弱+促转股 | CV↑Prem↓通常上行 | 下修预期→事件sleeve加分,非主线 |
| 到期赎回 | 持有到期 | 向赎回价(106–115)收敛 | <6m观察,<30d硬排除 |

## 3. 信用/尾部风险 — 2021 后现实（一等约束）
> ★ **相对 PRD v1 §3.2 最重要校正。** "正 YTM=下有保底/债底安全"在 **2021 年前**(转债"零违约"信仰)大致成立，**2021 年后已证伪**。

### 3.1 现实: 违约/退市是真实事件
2021 后实例(说明性): **搜特退债**(首只实质违约/退市转债,正股退市→转债退市,巨亏)、**蓝盾退债**、**鸿达转债**等；退市整理期可跌至 10–30 元甚至更低，回收率远低于面值。机制: 正股财务恶化/面值退市/重大违法退市→转债跟随退市→债底失效。**转债信用风险绑定正股退市风险**(A股转债特有尾部)。结论: 双低天然偏好低价，而**低价往往正是信用瑕疵的定价**——双低与信用尾部**正相关**，是策略最大隐藏风险(踩雷)。

### 3.2 硬排除清单（一票否决，优先于一切打分）
| 排除项 | 默认阈值[PM] | 理由 |
|---|---|---|
| 评级过低 | 主体或债项 **< AA-** | 低评级=高违约/退市概率 |
| 评级下调/观察 | 近6月下调或负面观察 | 评级迁移=违约前导 |
| 退市风险 | 正股 \*ST/ST、面值退市预警(股价<1.5元)、财务类退市指标触及 | 正股退市拖死转债 |
| 信用事件 | 发行人/关联方违约、重大诉讼、立案、审计非标、大额逾期 | 实质信用恶化 |
| 临近到期 | 剩余 **<30天**(<6月降权观察) | 时间价值耗尽+兑付不确定集中 |
| 临近/已公告强赎 | 强赎进度≥红线或已公告行使 | 防按面值被赎、价格断崖 |
| 低流动性 | ADV **<2000万** 或近20日有零成交 | 无法调仓、冲击失控 |
| 小余额 | OS **<1亿** | 强赎/操纵风险高、冲击大 |
| 极端高价 | P_cb **>150元**[PM] | 债底保护几乎消失，纯赌股性 |
| 停牌 | 当前停牌 | 无法交易/估值失真 |

评级用**最新**(中证鹏元/中诚信/联合/东方金诚)，监控评级行动公告，**主体与债项取低者**。

### 3.3 顶层失效条件（写入 thesis.invalidation）
① 池内个券信用事件/正股退市风险(债底失效)；② 信用利差快速走阔(中债 AA 利差周度>X bp[PM])→系统降双低敞口；③ 正股系统性破位+转债跟跌；④ 流动性骤降(池内 median ADV 周环比腰斩)；⑤ 监管/政策冲击(转债再融资/退市新规)→重估池。

### 3.4 处理顺序（强制，不可颠倒）
```
全量池 →[1]§3.2 硬排除过滤(信用/退市/流动性/强赎/到期/规模) →[2]§1.3 双低打分排序 →[3]§2 条款状态机 →[4]§4 周频再平衡+偏离带+成本 →[5]§3.3 顶层失效实时监控(可中断)
```
信用硬门**最前**。任何"先排序再剔除"都会让双低分把信用瑕疵券排前诱导买入。

## 4. 周频再平衡

### 4.1 为何周频(尽管 T+0)
换手/成本(双低是中低频信号,日频换手吞噬 alpha)；信号噪音(日频排名抖动);运营/合规(人在环审批按周可行);容量。

### 4.2 数量/权重
**持仓 20–30 只[PM]**(分散信用尾部;<15 过集中,>40 稀释 alpha+运营负担)。单券上限 6%、单发行人 6%(同发行人多券合并)。默认**双低分加权+上限截断**;亦可等权(更稳、更低换手)[PM]。

### 4.3 入场/出场
入场: 过全部 §3.2 硬排除 且 综合分进前 N(N=仓数+缓冲)且条款健康。出场(任一): 双低分跌出前 M(M=N+缓冲,§4.4);命中任一硬排除→**立即剔除(不等再平衡日)**;命中强赎红线→强制了结;触发顶层失效→降敞口。

### 4.4 缓冲带（防抖动换手）
`入选: 排名≤N_in(如20); 保留: 已持且≤N_out(如30,>N_in); 剔除: 已持且>N_out`。或分数带(持仓券双低分劣化>Δ才换,如+10点)[PM]。权重再平衡偏离带(接 risk-parity): 个券权重漂移>±1.5% 或风险预算偏离>阈值才调。

### 4.5 成本/滑点
| 项 | 默认[PM] | 说明 |
|---|---|---|
| 佣金 | 0.1‰–0.2‰(万1–万2,单边) | 低于股票 |
| 印花税 | **0**(转债免) | 与股票区别 |
| 冲击/滑点 | 8–15bp(按订单额/ADV分档) | 订单>5%单日ADV升档;小余额更高 |
回测统一: `transaction_cost_bps=15`(佣金+冲击,单边)、`slippage_bps=10`、`ADV≥2000万`。须**计入成本后**报 Sharpe/CAGR + **换手**(双低周频典型年化 3–8 倍[PM]监控)。

### 4.6 临停/微结构执行告诫
转债**无涨跌停**但有**临停**: 盘中±20%→临停(至14:57前)、±30%→再临停(新券首日另规)。临停期无法成交,决策包须标"接近±20%的券有临停执行风险",下单留余量。**T+0 vs 正股 T+1 错配**: 转债当日可平,转股得正股 T+1 才可卖(隔夜风险)→强赎处置"市价卖转债"通常优于"转股再卖正股"。最小变动 0.001 元,10 张起。执行: 周五盘后生成→下周一开盘人工,高波动券避开集合竞价首笔,用 VWAP/限价分批[PM]。

## 6. 须 PM/风控拍板（[PM] 汇总）
双低权重 k/regime 旋钮 · §3.2 全部硬排除阈值 · 持仓数 20–30 与 6% 上限、等权 vs 加权 · 缓冲带 N_in/N_out 与权重偏离带 · 成本档位与年化换手上限 · YTM 税后口径 · 信用利差失效阈值 · 临到期处置边界 · 下修是否单列事件 sleeve · 数据源选型(推荐 Wind)+license · **CB sleeve 进 risk-parity 协方差方式(v1 单资产 vs v2 股性 delta+久期)** · 合规口径(法务).

## 7. 对 PRD v1 §3.2 的校正清单
| PRD v1 | 问题 | 校正 |
|---|---|---|
| "正 YTM=下有保底/债底安全" | 当无条件保底;2021后证伪 | BF/YTM 为条件下限(无违约假设);信用升为硬排除一等约束(§3) |
| 双低仅"价<115+溢价<25%" | 缺组合打分公式/权重 | `P_cb+k*Prem`/排名标准化,k 为 regime 旋钮(§1.3) |
| "强赎规避(临近减仓)" | 缺触发计数/预警带,未说 YTM 失效 | 15/30 进度状态机+预警带+强赎后 YTM 置 N/A(§2.1) |
| 信用仅作软维度 | 与双低偏好低价正相关的踩雷被低估 | 硬排除清单一票否决,先于打分(§3) |
| 条款阈值写死 | 逐券不同 | 标最常见值+变体,逐券解析(§2) |
| 到期"≈106–110" | 部分更高 | 典型 106–115,逐券读(§2.4) |
| 数据源并列 | 未指集思录无 API | Wind 为生产权威(§5) |

*尾注: 决策辅助，非投资建议；纯债价值与 YTM 均以"无违约/持有到期"为前提，强赎或信用事件下失效；回测不代表未来；私募非公开。所有 [PM] 阈值须经基金经理与风控/合规确认。*
