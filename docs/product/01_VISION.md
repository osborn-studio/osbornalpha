# 01 · 愿景（Vision）

> 术语以 [`00_TERMINOLOGY_CONSISTENCY.md`](./00_TERMINOLOGY_CONSISTENCY.md) 为准。

## 1. 一句话愿景

**osbornalpha 是你的 AI 投资 PM 工作台：把股票池交给一个由多位投资大师视角与一名 PM agent 组成的团队，每天产出可读完、可追溯、敢被打脸的决策辅助简报，覆盖 A股 / 港股 / 美股。**

它不是又一个行情软件，也不是又一个 ChatGPT；它是一个**纪律化的投研副驾**——把"应该看什么、谁怎么看、为什么这么看"结构化地交付给你，决策仍由你做。

## 2. 定位（Positioning）

| 维度 | osbornalpha 的选择 |
|---|---|
| 品类 | AI 投资监控工作台（research/monitoring copilot），非交易终端、非荐股服务 |
| 时间频率 | 日频为主（每日简报 + 雷达扫描），非实时分钟级 tick |
| 资产范围 | A股 / 港股 / 美股（多市场统一视图），不含期权/加密/自动下单 |
| 交付形态 | Web 工作台（`/dashboard` 等）+ 主动推送（Telegram / Email）+ Agent 端（John Cameron CLI/Hermes） |
| 角色 | 决策辅助（decision support），不构成投资建议；所有外发强制带免责声明 |

一句话边界：**给信号、给视角、给可追溯的判断；不替你下单，不承诺涨跌。**

## 3. 目标用户（Target Users）

### 3.1 主用户：跨市场的认真个人投资者
持有数只到数十只标的、横跨 A/H/US，关注基本面与宏观、希望有纪律但时间有限的个人投资者。他们已会用券商 App 看行情，缺的是**每天有人替他扫一遍池子、把多空理由摆清楚**。产品作者本人即第一用户（dogfood）。

### 3.2 早期可售卖用户：想要"投研工作流"的进阶散户 / 小型工作室
愿意为「多大师视角 + PM 决策管线 + 历史可追溯」付费、把它当成个人投研流水线的一部分。对应 Free → Pro 升级路径。

### 3.3 非目标用户
高频交易者、纯技术派短线客、要"代客理财/荐股许可"的人群——产品明确不提供任何投资建议许可服务。

## 4. 差异化（Differentiation）

1. **多大师视角的结构化辩论**：9 位 persona（巴菲特/芒格/德鲁肯米勒/马克斯/林奇/伯里/张坤/李录/段永平）对同一标的各自独立输出 stance + confidence + cites，强制引用传入的真实数据点，禁止泛泛而谈——这是把"投资委员会"产品化，而非单模型一句话。
2. **PM agent 的可追溯决策**：John Cameron（Druckenmiller DNA）以五段式管线自上而下决策（择时总闸 → 卡脖子选股 → 评级排序 → 持仓/校准叠加），且**命中由代码裁定**（append-only 战绩 journal + 确定性打分），LLM 不得自评命中率——反过拟合、反自夸。
3. **每条结论可追溯、敢被打脸**：信号必带来源 + 信心分 + 免责声明；历史简报归档可回看；强调"决策辅助"而非"预测"。
4. **多市场一体化**：A/H/US 在一个池子、一个简报里统一监控，省去多 App 来回切换。
5. **成本可控的双 LLM 路由**：默认 DeepSeek（按成本优先），Anthropic Claude 作高级推理回退，单次调用成本可估、可降级。
6. **多租户 SaaS 底座**：Supabase Auth + 全表 RLS 隔离，账户间数据零泄露；产品全门禁，付费墙在最前。

## 5. 北极星指标（North Star Metric）

**北极星：DARR — Daily Active Reader Rate（每日活跃阅读率）**
= 当日打开并读完简报的用户数 / 当日有简报的用户数。

它直接度量"产品是否每天真的被用、被信"，比注册数/MAU 更贴近价值。原始单用户口径（作者自测）目标 ≥ 80%。

### 配套指标（护栏 + 健康度）
| 指标 | 含义 | 目标方向 |
|---|---|---|
| 30 天信号命中率 | 雷达/委员会信号经回测的可靠性（代码裁定） | ≥ 60% |
| 简报调度成功率 | 每日定时简报成功生成+推送比例 | ≥ 99% |
| 单日 LLM 成本 | 每用户/每日 LLM 花费（成本护栏） | ≤ $5（可降级） |
| 生成时延 | 单次简报端到端 | ≤ 5 分钟 |
| Free→Pro 转化（上线后） | 付费转化率 | 持续提升 |

## 6. 三年方向（North Star 的延伸）

- 近期：把"每天值得读、读完有用"的单人体验打磨到 dogfood 满意，跑通多租户门禁与 Free 套餐。
- 中期：上线 Pro（Stripe 实付）+ 真功能闸；委员会/PM 决策从辅助走向"可复盘的投研工作流"。
- 远期：自定义投资人视角、中英双语、真 multi-agent 辩论、Agent 端（John Cameron）与 Web 端打通成一个"投资 PM 操作系统"。
