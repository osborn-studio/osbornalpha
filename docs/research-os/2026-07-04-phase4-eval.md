# Research OS Phase 4：Eval Harness Implementation Plan

> Spec: `docs/research-os/product-technical-spec.md` §4.8/§10 Phase 4。Phase 1-3 已上线（main=a13571d，498 测试）。eval_cases/eval_runs 表 Phase 1 已建，无迁移。

**Goal:** 历史时间点评测：给定 as_of_date + 当时可见材料 → agent 生成 memo 输出（不落 memos 表）→ LLM 评审员按 6 维 rubric 对照真实后续事件打分 → 失败模式沉淀。**验收（spec §10）**：案例可运行；每次 run 有评分和失败模式。

**Architecture:** 沿既有全部约定。**builder≠judge 角色分离**：生成与评审是两个独立 prompt/调用（同 provider 不同 system 角色），评审 prompt 看不到生成 prompt，只看输出+expected+rubric。
**已知局限（诚实声明，写进 Eval Lab 页脚与本计划）**：预训练 LLM 自带 as_of_date 之后的世界知识，无法真正"时间盒"——缓解手段=生成 prompt 强制"假设今天是 {as_of_date}，只准使用提供材料，材料外断言一律标 LOW_CONFIDENCE"，评审维度"引用质量/过度自信"专门惩罚无据断言。这不是完美回测，是研究纪律评测。

**Branch:** `feat/research-os-phase4`。禁触 KlineChart.tsx / composer.ts；不碰 SaaS 文件。

### T1: Eval 服务（TDD）

**Files:** `src/lib/research/evals.ts`（+test）、`src/lib/research/eval-prompt.ts`（+test）

- **默认 rubric**（spec §4.8 六维，存 case.rubric 可覆盖）：`factual_accuracy / citation_quality / counter_arguments / risk_identification / invalidation_quality / overconfidence`（overconfidence 反向：越自信越无据分越低），每维 0-10 + 权重均等。
- `createEvalCase(db, {title, as_of_date, source_document_ids, expected_notes, rubric?})`：校验 sources 存在且非空、as_of_date 合法；visible_material=ids；expected={notes}；audit_log('eval.case_create')。
- `buildEvalGenPrompt(evalCase, sources)` 纯函数（TDD）：注入 as_of_date 时间盒指令 + 材料（id+title+摘录）→ 要求输出 memo JSON（复用 §4.4 十段 schema——**直接复用 memo-prompt.ts 的输出 schema 常量**，不复制粘贴）。
- `buildEvalJudgePrompt(agentOutput, evalCase, rubric)` 纯函数（TDD）：注入输出 + expected.notes + rubric 维度说明 → 要求输出 {scores:{维度:0-10}, failure_modes:string[], rationale_per_dimension:{...}}；明示"对无引用断言与过度自信从严"。
- `runEval(db, caseId)`：gen 调用 → judge 调用 → 校验 scores 键齐全且 0-10（越界 clamp 并记 failure_modes 'judge_out_of_range'）→ total=加权均值 → 落 eval_runs（agent_output 全量 + 双 provenance {gen, judge}）→ audit_log('eval.run')。生成/评审任一失败 → 结构化错误不落半截 run。
- TDD：两 prompt 组装（时间盒指令在场/schema 复用/维度注入）、score 校验 clamp、runEval 用假 LLM 注入（依赖注入 `llmCall` 参数，Phase 2 monitor 同模式）成功+半途失败两例。
- Commit: `feat(research): eval harness service (time-boxed gen + separated judge)`
