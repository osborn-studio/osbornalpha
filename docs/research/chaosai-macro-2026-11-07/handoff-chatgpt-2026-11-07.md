**美林时钟的计算语义已经明确，UI 应消费结果，不另算一套。**

输入是地区、每个指标的 latest/prev/prev3m 观测，包含 observation_id、period_end、value_text。比较周期由既有读取层决定；prev 是窗口内上一条存在的期间，不应在文案中一概宣称一定是严格相邻月。prev3m 找精确的三个月前期间，季度指标对应上一季度。缺失比较值不会被填成 0。

当前引擎：

1. 按指标类型选第一条命中规则。
2. 对每个象限计算 weight × support。
3. 汇总所有指标的象限贡献。
4. 总分大于 0 且命中权重覆盖率至少 0.6，才输出归一化结果。
5. 输出主状态、次状态、分数、norm、coverage、margin_pp、growth_axis、inflation_axis。
6. 为每一项记录 observation_id、rule_id、weight、support、contribution。

公式：

```text
contribution(i, q) = weight(i) × support(rule(i), q)
score(q) = sum_i contribution(i, q)
norm(q) = score(q) / sum_all_quadrants score
coverage = matched_weight / total_region_weight
```

分母包含 missing/restricted 目录项对应的权重；不能删除缺失指标后把覆盖“凑到 100%”。目录已核实项目数与权重覆盖率是两个指标。active 但没有命中规则的指标也可能不计入 matched_weight，不能把“有数据”自动等同于“参与本次分类”。

当前美国权重总和 100，中国权重总和 125。中国分母不是 100 不构成错误：权重是相对权重，最终另做归一化。缺少中国 LPR 5Y 目录项是实际差距，不是已有字段换名即可解决。

注意现有字段的含义：

| 字段/概念 | 正确解释 |
|---|---|
| weight | 方法配置的相对权重，不是原始数据 |
| support | 命中规则给各象限的支持系数，不是统计估计概率 |
| contribution | 权重乘支持系数的贡献分 |
| norm | 规则分数归一化占比 |
| coverage | 本次规则命中的权重覆盖 |
| margin_pp | 主次象限的归一化占比之差，不是预测置信区间 |
| growth_axis / inflation_axis | 由规则支持度形成的轴值，不应冒充 GDP/CPI 实测值 |
| first_seen | 系统第一次取得数据的时间，不是历史官方发布时间 |
| calibrated probability | 要由明确校准与发布流程支持，不能仅给 norm 改名 |

snapshots.ts 在 publishRegion 中计算并记录分类和贡献；判断开关主要控制后续发布钩子/读取展示，并不意味着关掉后根本没有内部计算。判断结果保存在受服务端访问控制的数据路径中，不能为赶 UI 进度改成匿名直接读取内部表。

MacroJudgmentSlot 的已见链路是：读取 /api/judgments 中对应地区的判断；只有 input_snapshot_id 与当前概览快照相同，才将该快照的贡献作为依据；展开 Basis 时读取 /api/macro/snapshots/{snapshotId}。若 F4 返回异常，现有设计显示不可用，不回退到另一份前端“自算概率”。以 #120 合并后的实际契约为准。

还有三处定量解释问题应独立处理：

- 广义美元指数 102.45 被套入“≥4.5 的限制性利率”规则；USDCNY 7.12 也被套入同一类利率阈值。不同量纲不能这样直接共用阈值。

其公式可以从已读源码明确写成：

`contribution[i,q] = weight[i] × support[matched_rule(i),q]`

`score[q] = Σ contribution[i,q]`

`normalized_score[q] = score[q] / Σ score[all_quadrants]`

命中规则的权重之和与地区总权重之比用于判断覆盖是否足够。缺失/受限指标仍在分母里，避免因为删掉缺失项而虚增覆盖。它的“目录已核实 6/8 或 8/11”是项目个数口径，不能直接当成模型的有效权重覆盖率。

美国权重为 DFF 25、美债 15、广义美元 10、CPI 15、失业率 10、PPI 5、ISM 15、VIX 5。中国权重为 CPI 10、PPI 15、PMI 15、GDP 5、M2 10、出口 10、中债 15、人民币 5、LPR 1Y 10、MLF 10、社融 20。当前目录没有 LPR 5Y，与 ChaosAI 的中国时钟输入并不完全相同。

这意味着最值得立即复用的工作是：把已有贡献数据接到四象限卡片，每个象限显示主要贡献、反向证据和展开明细；给规则 ID 配置可读中文、补上本次观测值与数据期；保证卡片和展开表由同一份结果生成并能算回总分。**这项工作不是重新造一个宏观评分引擎。**

**OsbornAlpha 的采集与审计架构也已经超过“展示用数据 JSON”这一层。** 已读目录与 PR 记录显示，美国通过 FRED 公开 CSV；中国使用 AKShare 辅助访问已核实的官方主机，并保留原始响应、解析定位、观测版本、批次状态和快照。

中国当前接入的是：国家统计局的 CPI/PPI/PMI/GDP/M2/出口，ChinaBond 的国债收益率，SAFE 的人民币中间价。M2、出口的原始发布者与取得渠道分别记录。派生处理区分“价格指数计算同比”“上年同期=100 减 100”“日频取月末”等，不能像统一画折线那样忽略各自定义。[固定版本指标目录](https://github.com/osborn-studio/osbornalpha/blob/78e9c4d7fcedfbd38e35868319f3fff131431aa6/src/lib/macro/catalog.ts)。

四个特别容易在复刻中搞错的差别：

- OsbornAlpha 的广义美元是 DTWEXBGS；ChaosAI 部分展示混入 DXY。两者不是换个名称就能互相替代。
- OsbornAlpha 的人民币是中间价，单位为人民币元/100 美元；ChaosAI 标的是 USDCNY。若做更直观展示，可以显式换算单位，不能暗中改称在岸即期。
- OsbornAlpha 的 WTI 是 EIA 现货序列；ChaosAI 的 CL=F 是期货 ticker。历史收益、交易日与经济含义要区分。
- 国债收益率变化的 bp 不是债券投资总回报。如果想显示“持有债券赚了多少”，需要债券价格或总回报指数，不能由收益率端点直接冒充。

传导页实见的利差为 4.94 − 1.65 = 3.29pp，输入是同为 2026-10-31 的美国和中国十年债月末值。这条已正确使用两个国家的同期限收益率；方向实际为“美国减中国”，展示名称最好进一步写明。相关源码会在数据期不一致时返回缺失，而不是强行相减。[传导实现](https://github.com/osborn-studio/osbornalpha/blob/78e9c4d7fcedfbd38e35868319f3fff131431aa6/src/lib/macro/strategy/transmission.ts)。

**展示上，ChaosAI 优势在组织方式，不在某一种高级图表库。** 它把用户的阅读路径做成“当前判断 → 关键驱动 → 定量展开 → 历史情境 → 资产含义”。OsbornAlpha 的基础能力散在概览表、详情页、传导页和关联表单里，用户第一眼很容易低估已经完成的工作。

建议优先完成以下几项可验证的展示改进：

1. 美林时钟采用美国/中国四象限卡片；主状态与次状态明确，卡片里直接给前三个有效贡献。逐项展开应包含中文指标名、值与数据期、规则中文、权重、支持系数、贡献值和证据入口。主卡百分比/分数与展开合计必须对账；分数与校准概率使用不同的名称。
2. 概览保留紧凑指标表，同时把重要指标做成可展开大图卡。直接复用已有 IndicatorDetail 与 MacroLineChart，避免另造一份不同口径的图表数据。
3. 图中默认突出真正发生的政策变化，FOMC 会议圆点作为可选层。当前 DFF 图中会议点较密，容易压过曲线和政策变化。事件说明可在图下按时间排列，控制文字密度。

5. 关联入口先给几组有数据的默认结果卡片，再让用户修改窗口和滞后。现有“预填表单”会让首次进入的用户觉得尚无分析内容。
