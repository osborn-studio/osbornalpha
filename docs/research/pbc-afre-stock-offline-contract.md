## Parser contract

`parsePbcAfreStockArticle` is a standalone offline function, intentionally absent from the active registry and all collectors. It accepts fatal UTF-8 bytes (1–262144 bytes) and a caller-supplied receipt. Two exact verified HTTPS article URLs are allowlisted with their own year/month and publication date; no redirects, network fetch or arbitrary source IDs are accepted. The caller must establish that bytes came from that URL; receipt validation is not network authenticity verification.

The function requires unique ArticleTitle/PubDate metadata, a title matching that URL’s verified month, its exact verified publication date after period end and no later than retrieval's UTC date, and exactly one headline paragraph. A strict headline grammar binds period, total stock in 万亿元 and an explicit published percent growth/decline. All paragraph bodies must be plain text; any entity or inline markup is rejected to avoid concealed duplicate headlines. Unsupported layout, encoded/inline headline markup, missing values, wrong units, flow titles, mismatched months or duplicate candidates throw. Comments/scripts/styles are masked while preserving character offsets. This deliberately narrow grammar is not a general HTML parser or an unrestricted historical archive contract. Version `pbc-afre-stock-article/2` adds July and binds both publications to their verified dates; corrected values at the same publication date remain separate byte evidence, while a changed publication date requires source re-verification.

Output is a research candidate, **not** `ParsedPoint`/`ObservationWrite`: fixed series ID, month end, canonical decimal percent text (8.8, not 0.088), unit, `revisable: true`, publication date, retrieval timestamp, source URL, parser version, full-byte SHA-256 and UTF-16 value range into the decoded evidence. The range is not an ingest Locator. Never recompute growth from rounded stock balances. A changed value yields changed evidence; no observation version or automatic supersession is assigned. Published date never substitutes for first-seen availability.

Version `pbc-afre-stock-article/3` copies only `sourceUrl` and `retrievedAt` from the receipt. Structurally compatible callers may carry additional admission metadata; those extra properties are ignored, so they cannot overwrite validated article fields or add availability/ingest fields to the candidate. July and August regression cases demonstrate this boundary with conflicting publication, period, value, series and unit metadata. The verified sources and publication checks are unchanged.
