# G1 多语言（i18n）— 设计文档

**日期**: 2026-07-03　**状态**: 已获用户批准
**背景**: 全球化战略第一段。现状审计：166 个文件含中文（60 app / 33 components / 73 lib）、无 i18n 库、设置页语言选择器未接线（只写 localStorage 的 'lang' 键）、`<html lang="zh-CN">` 硬编码、4+ 处 `toLocaleDateString('zh-CN')` 硬编码。

## 0. 已确认决策

| 决策 | 结论 |
|---|---|
| 首发语言 | **zh + en**；字典结构预留 ja/ko/zh-TW（后续只加翻译文件零改代码） |
| URL 策略 | **公开页 locale 前缀**（`/en`、`/en/about`…，SEO 双语 metadata）+ **应用内按偏好**（URL 不变） |
| 翻译生产 | LLM 翻译 + 用户抽检；金融术语表先行统一 |
| 框架 | **next-intl**（App Router 原生，middleware 与现有 auth gate 组合，next-intl 先行） |
| Locale 解析链（应用内） | `user_preferences.language` → cookie `NEXT_LOCALE` → `Accept-Language` → 默认 `zh`（纯函数 TDD） |

## 1. 分段

- **G1a 框架+壳层**：next-intl 装配（`messages/{zh,en}/*.json` 按域分文件：common/landing/auth/settings/portfolio/today/intel/tools/copilot/errors）；middleware 组合（locale 检测在 auth 之前，公开页前缀路由，(app) 内不加前缀）；`<html lang>` 动态；设置页语言选择器**真接线**（写 cookie + 登录态 upsert user_preferences.language，修掉现有 TODO）；`src/lib/i18n/`（locale 解析纯函数、`formatDate/formatDateTime(locale)` 替换 4 处 zh-CN 硬编码、formatPrice 保持显式货币参数不变）；**落地页 + login/register/forgot/reset 全套抽离+英译**（双语 metadata generateMetadata）；**金融术语表** `messages/GLOSSARY.md`（浮盈=Unrealized P&L、已实现=Realized、止损=Stop Loss、仓位=Position、建仓/平仓=Open/Close Position、择时=Market Timing、标的=Ticker/Instrument、复盘=Review、股票池=Watchlist、驾驶舱=Cockpit、简报=Brief、雷达=Radar、九人观点=Committee Perspectives、时长卡=Time Pass 等——G1b/c 所有翻译必须遵循）。
- **G1b 应用内页面**：(app) 六板块页面 + 33 组件文案抽离至字典 + 英译。**按目录 fan-out 并行 subagent**（today/ portfolio/ intel/ tools/ watchlist+stock/ components-shared/ 六路），每路独立 commit+审查；G1a 合并后启动。
- **G1c 动态内容**：agent 方法 systemPrompt 追加语言指令（按请求 locale："请用英文回答/Respond in English"——prompt 主体保持中文，输出语言受控）；雷达/简报生成器用户可见标签（level_label、章节标题）字典化；API 用户可见错误（配额/认证等）+ QuotaNotice/UpgradeCard 文案；九人 persona 显示名/风格标签（LLM prompt 内部保持中文）。
- **明确不动**：agent 工具注册表 description/category（LLM 内部上下文）、mock 数据公司名与分组名（G1b 视工作量顺带或留存）、代码注释。

## 2. 关键接缝

- middleware：next-intl `createMiddleware`（localePrefix: 'as-needed'，defaultLocale zh，locales [zh,en]）只作用于公开路径集合；auth gate 逻辑原样接续；(app) 内 locale 由 `getRequestConfig` 从 cookie/user-pref 解析（服务端读 user_preferences 需 supabase——在 layout 层解析一次注入 provider）。
- 客户端组件统一 `useTranslations('域')`；服务端 `getTranslations`。
- 测试：locale 解析链 TDD；E2E 新增 `/en` 落地 200+英文断言、`/`（zh）不回归；252 基线不回归。
- 风险：middleware 组合次序（intl 先 auth 后）需 E2E 锁定登录跳转不被 locale 前缀污染（`/en/login?next=…` 场景）。

## 3. 上线后

设置页切 English → 全站即时英文（含 Copilot 回答语言）；google 可索引 /en 落地页。ja/ko/zh-TW = 复制字典文件翻译即可。
