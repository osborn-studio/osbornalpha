# Earnings Research Book

Use this for Workflow A when the single-stock research book is earnings-focused or when source files include filings, earnings releases, transcripts, or investor decks.

Read:

- `references/source-policy.md`
- `references/report-contract.md`
- `references/chapter-template.md`

## Inputs

- company name and ticker
- reporting period
- source inventory
- source files or retrieval notes
- prior B/C thesis context when available

## Output

Create a research book directory with:

- source inventory
- references database
- chapter markdown files
- quote ledger with short original quote, Chinese translation, interpretation, and investment implication
- missing-source list

## Hard Rules

- Do not invent source quotes.
- Keep source quotations short and attributable.
- Separate facts, management claims, inference, and speculation.
- Mark unavailable data as missing-source.
- End with research-only risk language unless Workflow D is explicitly requested.
