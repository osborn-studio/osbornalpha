# Sector Value Chain Templates

Quick-reference chain maps for common sectors. Use these as starting points, then customize based on the specific sub-sector.

## AI / Semiconductor

```
Layer 1: End Demand — Cloud hyperscalers (AWS, Azure, GCP, 阿里云), enterprise AI
Layer 2: Systems — GB300 NVL72 rack, TPU pod, AI factory
Layer 3: Interconnect — 1.6T/3.2T optical modules, switches, DSP/retimer
Layer 4: Compute Silicon — GPU (NVIDIA, AMD), ASIC (Broadcom, Marvell), HBM
Layer 5: Advanced Packaging — CoWoS, EMIB, hybrid bonding
Layer 6: Foundry — 3nm/2nm logic, specialty nodes
Layer 7: Equipment — EUV lithography, etch, deposition, metrology
Layer 8: Materials — Silicon wafers, photoresist, specialty gases, substrates
```

Key bottleneck questions:
- Which layer has the longest lead time?
- Where is capacity most concentrated (single supplier)?
- What requires the longest qualification cycle?

## New Energy Vehicle (NEV)

```
Layer 1: Consumer — End buyer, fleet operator
Layer 2: OEM/Brand — BYD, Tesla, NIO, XPeng, Li Auto, Xiaomi
Layer 3: Domain Controller / ADAS — Autonomous driving compute platform
Layer 4: Powertrain (三电) — Battery pack, motor, electronic control
Layer 5: Core Components — IGBT/SiC power modules, BMS, thermal management
Layer 6: Battery Materials — Cathode (LFP/NCM), anode, electrolyte, separator
Layer 7: Raw Materials — Lithium carbonate, cobalt, nickel, phosphorus
```

Key bottleneck questions:
- Which component has the lowest localization rate in China?
- Where are margins compressing vs expanding?
- What's the SiC vs IGBT transition timeline?

## Energy Storage

```
Layer 1: End User — Grid operator, C&I, residential
Layer 2: System Integrator — Full BESS solution provider
Layer 3: Battery Pack — Module/pack assembly
Layer 4: Battery Cell — LFP cell manufacturing (280Ah/314Ah)
Layer 5: Core Materials — Cathode (LFP), anode (graphite/silicon)
Layer 6: Raw Materials — Lithium, phosphorus, graphite
Layer 7: Power Electronics — PCS (inverter), BMS, EMS
```

Key bottleneck questions:
- Where is cell capacity utilization vs demand?
- Which layer has the best pricing power?
- Is the bottleneck in cells, power electronics, or grid connection?

## Humanoid Robotics

```
Layer 1: End User — Manufacturing, logistics, service
Layer 2: Robot OEM — Full humanoid robot integrator
Layer 3: AI/Software — Embodied AI, motion planning, perception
Layer 4: Actuators/Joints — Rotary actuator, linear actuator
Layer 5: Precision Components — Harmonic reducer, RV reducer, ball screw
Layer 6: Sensors — 6-axis F/T sensor, tactile sensor, vision
Layer 7: Motors/Drivers — Frameless torque motor, servo driver
Layer 8: Materials — Rare earth magnets, specialty steel, carbon fiber
```

Key bottleneck questions:
- Which component has the highest cost share in the BOM?
- Where is the precision manufacturing bottleneck?
- What's the gap between Chinese and Japanese/German suppliers?

## Pharma / Biotech

```
Layer 1: Patient/Healthcare System — Hospital, pharmacy, payer
Layer 2: Drug Product — Innovative drug, biosimilar, generic
Layer 3: CDMO — Contract development and manufacturing
Layer 4: API (原料药) — Active pharmaceutical ingredient
Layer 5: Intermediates — Key intermediates, building blocks
Layer 6: Raw Materials — Chemical reagents, solvents, catalysts
Layer 7: Equipment/Consumables — Bioreactor, chromatography, filtration
```

Key bottleneck questions:
- Which API/intermediate has the fewest DMF filers?
- Where is capacity booked out for 12+ months?
- What's the regulatory barrier (FDA/EMA/NMPA inspection timeline)?

## Solar PV

```
Layer 1: End User — Utility-scale, C&I, residential
Layer 2: System — Module, inverter, mounting, BOS
Layer 3: Cell — TOPCon, HJT, BC cell manufacturing
Layer 4: Wafer — Mono wafer slicing
Layer 5: Polysilicon — High-purity polysilicon
Layer 6: Equipment — Cell/wafer production equipment
Layer 7: Materials — Silver paste, EVA/POE film, backsheet, glass
```

Key bottleneck questions:
- Which layer has the highest capacity concentration?
- Where is the technology transition (PERC→TOPCon→HJT) creating winners/losers?
- What raw material (silver, quartz crucible) is supply-constrained?

## Wind Power

```
Layer 1: End User — Utility (state-owned power groups)
Layer 2: Wind Turbine OEM — Full turbine manufacturer
Layer 3: Key Components — Blade, gearbox, generator, converter
Layer 4: Core Parts — Main bearing, pitch bearing, yaw bearing
Layer 5: Raw Materials — Carbon fiber, rare earth (NdFeB), steel, resin
```

Key bottleneck questions:
- Which bearing type still relies on imports (SKF/Timken)?
- Where is the carbon fiber supply bottleneck?
- What's the offshore vs onshore margin divergence?
